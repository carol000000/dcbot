# dcBot 修改範本手冊

本文件提供可以直接改寫的範本。修改前先備份 `player.json`，並在每次修改後執行：

```bash
python -m py_compile dcBot/*.py
```

所有「新增斜線指令」的程式都要放在該模組的 `register(bot)` 函式內。

## 快速選擇：功能該放哪裡？

| 你要做的事 | 修改檔案 |
| --- | --- |
| `/規則`、`/公告` 等一般指令 | `command.py` |
| 收到「早安」等文字後回覆 | `text.py` |
| 猜拳、骰子、問答等小遊戲 | `game.py` |
| 金錢、道具、角色、農場 | `rpg.py` |
| AI 提問限制、AI 回覆流程 | `dcai.py` |
| Token、啟動公告、載入模組 | `dcbot.py` |
| 固定 Discord ID 與 AI 記錄設定 | `id.json` |

## 1. 新增一般斜線指令

**用途：** 新增 `/規則` 這類不需要玩家資料的指令。  
**放置位置：** `command.py` → `def register(bot):` 裡面。

```python
@bot.tree.command(name="規則", description="查看伺服器規則")
async def rules(interaction: discord.Interaction):
    await interaction.response.send_message(
        "1. 請互相尊重\n"
        "2. 不要洗版\n"
        "3. 有問題請聯絡管理員"
    )
```

重啟 Bot 後，在 Discord 輸入 `/規則` 測試。

### 帶有使用者輸入的指令

**用途：** 新增 `/說 內容:你好`。

```python
@bot.tree.command(name="說", description="讓 Bot 重複一句話")
@discord.app_commands.describe(內容="要讓 Bot 說的內容")
async def say(interaction: discord.Interaction, 內容: str):
    if len(內容) > 100:
        await interaction.response.send_message("內容最多 100 個字。", ephemeral=True)
        return

    await interaction.response.send_message(內容)
```

### 只有管理員可用的指令

**用途：** 新增 `/公告`，僅限有管理員權限的人使用。

```python
@bot.tree.command(name="公告", description="發送管理員公告")
@discord.app_commands.describe(內容="公告內容")
async def announce(interaction: discord.Interaction, 內容: str):
    if not interaction.user.guild_permissions.administrator:
        await interaction.response.send_message("你沒有管理員權限。", ephemeral=True)
        return

    await interaction.response.send_message(f"📢 公告\n{內容}")
```

### 刪除斜線指令

1. 在對應檔案中，找到 `@bot.tree.command(name="指令名稱"...)`。
2. 刪除該裝飾器及其下完整的 `async def ...` 函式。
3. 重啟 Bot，讓 `tree.sync()` 同步變更。

例如要刪除 `/規則`，就刪除前一節的整段 `rules` 函式，不要只刪除函式內容。

## 2. 新增或修改文字觸發回覆

**放置位置：** `text.py` → `on_message(message)` 裡面。

### 完全符合才回覆

使用者必須剛好傳送「幫助」才會觸發：

```python
if content == "幫助":
    await message.channel.send("可使用 /reg、/pet、/signin、/猜數字")
```

### 開頭符合就回覆

使用者傳送「晚安」、「晚安大家」都會觸發：

```python
if content.startswith("晚安"):
    await message.channel.send(f"晚安 {message.author.mention}！")
```

### 隨機回覆

`text.py` 已經有 `import random`，可以直接使用：

```python
if content == "笑一個":
    replies = ["呱呱！", "嘿嘿", "今天也要加油！"]
    await message.channel.send(random.choice(replies))
```

### 刪除既有文字觸發

找到對應的 `if content...` 程式區塊，連同區塊內的 `await` 一起刪除。例如不想再讓 Bot 回覆 `ping`，刪除 `simple_replies` 字典中的：

```python
"ping": "pong",
```

## 3. 新增迷你遊戲

**放置位置：** `game.py` → `register(bot)` 裡面。  
以下範本新增 `/骰子`，可擲 1 到 6 點：

```python
@bot.tree.command(name="骰子", description="擲一顆六面骰")
async def dice(interaction: discord.Interaction):
    point = random.randint(1, 6)
    await interaction.response.send_message(
        f"{interaction.user.mention} 擲出了 🎲 **{point}**"
    )
```

`game.py` 已經匯入 `random` 和 `discord`，不需要重複加入。

### 有等待輸入的遊戲範本

這個範本會等待同一位玩家在同一個頻道回覆，30 秒沒回覆則結束：

```python
@bot.tree.command(name="回答", description="回答問題遊戲")
async def answer_game(interaction: discord.Interaction):
    await interaction.response.send_message("請在 30 秒內輸入：呱")

    def check(message):
        return (
            message.author == interaction.user
            and message.channel == interaction.channel
            and message.content == "呱"
        )

    try:
        await bot.wait_for("message", check=check, timeout=30.0)
    except asyncio.TimeoutError:
        await interaction.followup.send("超時，遊戲結束。")
        return

    await interaction.followup.send("答對了！")
```

第一次訊息使用 `interaction.response.send_message()`；等待後的結果使用 `interaction.followup.send()`。

## 4. 新增 RPG 金錢／道具指令

**放置位置：** `rpg.py` → `register(bot)` 裡面。

### 發給自己金錢（示範）

以下是 `/工作` 範本。正式使用時建議再加上冷卻或每日限制，避免金錢無限增加。

```python
@bot.tree.command(name="工作", description="打工賺取呱")
async def work(interaction: discord.Interaction):
    result = await get_player_or_reply(interaction)
    if result is None:
        return

    data, uid, monster = result
    reward = random.randint(10, 30)
    data[uid]["money"] += reward
    save_data(data)

    await interaction.response.send_message(
        f"{interaction.user.mention} 打工完成，獲得 {reward} 呱！\n"
        f"目前金錢：{data[uid]['money']} 呱"
    )
```

### 新增一種道具：木頭

新增資料欄位時，必須同時改兩個地方，否則舊玩家會缺少資料。

1. 在 `rpg.py` 的 `update_all_players()` → `defaults` 新增：

```python
"wood": 0,
```

2. 在 `rpg.py` 的 `create_player()` → `monster` 新增：

```python
"wood": 0,
```

3. 新增 `/wood` 查看數量：

```python
@bot.tree.command(name="wood", description="查看木頭數量")
async def wood(interaction: discord.Interaction):
    result = await get_player_or_reply(interaction)
    if result is None:
        return

    data, uid, monster = result
    await interaction.response.send_message(f"你有 {monster['wood']} 個木頭。")
```

4. 重啟 Bot 一次。`on_ready()` 會自動替現有玩家補上 `wood: 0`。

### 扣除金錢購買道具

```python
@bot.tree.command(name="買木頭", description="花 10 呱購買 1 個木頭")
async def buy_wood(interaction: discord.Interaction):
    result = await get_player_or_reply(interaction)
    if result is None:
        return

    data, uid, monster = result
    price = 10
    if data[uid]["money"] < price:
        await interaction.response.send_message("金錢不足。")
        return

    data[uid]["money"] -= price
    monster["wood"] += 1
    save_data(data)
    await interaction.response.send_message(
        f"購買成功！剩餘 {data[uid]['money']} 呱，木頭共有 {monster['wood']} 個。"
    )
```

## 5. 修改現有 RPG 數值

不用寫新程式，直接搜尋並調整下列數值：

| 想改什麼 | 搜尋文字 | 例子 |
| --- | --- | --- |
| 簽到獎勵 | `data[uid]["money"] += 50` | 改成 `+= 100` |
| 挖礦消耗耐力 | `monster["atk"] -= 1` | 改成 `-= 2` |
| 挖礦經驗 | `add_exp(monster, 5)` | 改成 `add_exp(monster, 10)` |
| 種子價格 | `data[uid]["money"] < 50` 與 `-= 50` | 兩處都改成新價格 |
| 買種子數量 | `monster["seed"] += 10` | 改成新數量 |
| 石頭售價 | `register_sell("sellstone", ..., 5, ...)` | 第四個值改成單價 |
| 礦物售價 | `register_sell("sellore", ..., 20, ...)` | 第四個值改成單價 |
| 馬鈴薯售價 | `register_sell("sellpotato", ..., 10, ...)` | 第四個值改成單價 |

同一個價格若同時用在「顯示文字」與「計算」，兩處都要改，否則玩家看到的價格和實際扣款會不一致。

## 6. 修改 AI 行為

**放置位置：** `dcai.py` 與 `dcbot.py`。

### 更改提問最大字數

在 `dcai.py` 尋找：

```python
if len(prompt) > 100:
```

例如要改成 300 字：

```python
if len(prompt) > 300:
```

也把下方提示中的 `100` 改成 `300`。

### 更改 AI 冷卻

在 `dcbot.py` 尋找：

```python
commands.CooldownMapping.from_cooldown(1, 10, commands.BucketType.user)
```

三個值依序是「可用次數、秒數、限制對象」。例如每位使用者 60 秒可問 3 次：

```python
commands.CooldownMapping.from_cooldown(3, 60, commands.BucketType.user)
```

### 暫時關閉 AI

在 `dcbot.py` 的 `setup_hook()`，暫時註解這行：

```python
# dcai.register(self)
```

如果你的環境完全沒有 `GuaAI`，還需一併處理 `from ai import GuaAI` 與 `self.ai = GuaAI()`；否則 Bot 還是在啟動時失敗。

## 7. 更改啟動公告與自動封鎖頻道

固定 ID 都集中在 `id.json`。Discord 開啟開發者模式後，可右鍵使用者、頻道或身分組並選擇「複製 ID」。請填入純數字，**不要**填 `<#...>` 或 `<@&...>` 的標記文字。

### 啟動公告

在 `id.json` 的 `startup_announcement` 更改：

```python
"startup_announcement": {
    "channel_id": 1487084400993898547,
    "role_id": 1476234654053961941
}
```

頻道 ID 放 `channel_id`；要標記的身分組 ID 放 `role_id`。

### 自動封鎖頻道

在 `id.json` 更改：

```python
"moderation": {
    "monitored_channel_ids": [1410282161767972925, 1473947270050353298]
}
```

新增一個頻道時在括號內加入 ID：

```python
"monitored_channel_ids": [111111111111111111, 222222222222222222, 333333333333333333]
```

這個功能會封鎖非管理員在指定頻道發言的使用者。修改前請務必確認 ID 正確，建議先在測試伺服器驗證。

### AI 每個伺服器一份 JSONL 紀錄

`id.json` 的 AI 區塊可設定紀錄資料夾與提問上限：

```json
"ai": {
    "history_directory": "ai_history",
    "max_prompt_length": 800,
    "history_message_limit": 10,
    "history_character_limit": 4000,
    "history_read_max_bytes": 50000,
    "history_record_max_characters": 4000,
    "history_file_max_bytes": 1000000,
    "history_retention_bytes": 500000
}
```

Bot 收到 AI 提問時，會依 `message.guild.id` 讀取 `dcBot/ai_history/<伺服器ID>.jsonl`，只取最近 `history_message_limit` 筆，並限制總長度不超過 `history_character_limit` 字元後交給 AI。因此每個伺服器都有獨立記憶，不會混用其他伺服器的對話。私訊會使用 `direct_messages.jsonl`。

Bot 成功回覆後，才會自動建立或追加該 JSONL。第一行是伺服器記錄檔設定，之後每行都是一筆 `ai_chat` JSON 物件，包含時間、頻道 ID、使用者 ID、提問與回答。JSONL 是「一行一筆 JSON」，適合日後讀取或分析；請不要手動刪改檔案中間的單一行。

### 防止歷史紀錄太大

- `history_read_max_bytes`：每次最多讀取檔案末端多少位元組；不會把完整大檔載入記憶體。
- `history_record_max_characters`：每筆提問和回答最多保留多少字元。
- `history_file_max_bytes`：檔案超過此大小時自動壓縮。
- `history_retention_bytes`：壓縮後保留的近期資料量。

目前預設檔案最大約 1 MB、壓縮後保留最近約 500 KB。若伺服器對話量很高，可調低這些值。

### 降低 Prompt Injection 風險

程式已把 JSONL 歷史標示為不可信資料，並要求 AI 只回答本次 `<user_request>`，不可遵從 `<history>` 內的文字。這能降低「忽略前面指令」等惡意歷史訊息的影響，但無法保證任何純文字模型 100% 不受影響。

最重要的原則是：不要把 Token、管理員密碼、私密設定或能執行刪除／封鎖等操作的工具交給 AI；若使用的 AI API 支援 system/developer role，請把安全規則放在那個角色，而非只寫入一般提示文字。

此外，JSONL 的分伺服器檔案只隔離「程式讀取的紀錄」。若 `GuaAI` 物件本身有內建聊天記憶，請查它是否可清除記憶，或改成每個伺服器獨立 AI 實例，否則仍可能產生跨伺服器的模型記憶。

## 8. 新增一個全新功能模組（進階）

例如要建立 `music.py`：

1. 建立 `dcBot/music.py`。
2. 寫入最小架構：

```python
import discord


def register(bot):
    @bot.tree.command(name="音樂測試", description="測試音樂模組")
    async def music_test(interaction: discord.Interaction):
        await interaction.response.send_message("音樂模組已載入。")
```

3. 在 `dcbot.py` 的匯入區加入 `music`：

```python
from . import command, dcai, game, music, rpg, text
```

以及直接執行用的 `import music`。

4. 在 `setup_hook()` 加入：

```python
music.register(self)
```

5. 重啟 Bot，測試 `/音樂測試`。

## 9. 每次修改的安全流程

1. 先備份：`cp dcBot/player.json dcBot/player.backup.json`
2. 一次只修改一個功能。
3. 執行 `python -m py_compile dcBot/*.py`。
4. 重啟 Bot。
5. 在測試頻道執行該功能。
6. 確定正常後再修改下一項。

不要把 Bot Token、`.env` 或含有私人資料的 `player.json` 公開貼到 GitHub 或 Discord。
