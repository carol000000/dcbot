# dcBot 開發指南

這份文件說明如何啟動、閱讀與修改目前的 Discord Bot。主程式是 `dcbot.py`；其他檔案依功能分開，修改時請優先放在對應模組。

## 1. 第一次啟動

### 必要條件

- Python 3.10 以上
- 已建立 Discord Application 與 Bot，並取得 Bot Token
- 已安裝 `discord.py` 與 `python-dotenv`
- 若要使用 AI 問答，需能匯入 `GuaAI`（目前位置在 `/home/gua/GuaAI-Qwen`）

在專案根目錄安裝套件：

```bash
pip install -U discord.py python-dotenv
```

在專案根目錄建立 `.env`，內容如下。請勿把 Token 上傳到 Git。

```env
TOKEN=你的_Discord_Bot_Token
```

接著啟動：

```bash
python dcBot/dcbot.py
```

也可以在 `dcBot` 資料夾中執行：

```bash
cd dcBot
python dcbot.py
```

### Discord Developer Portal 設定

在 Bot 的 **Privileged Gateway Intents** 開啟：

- Message Content Intent：文字觸發與 AI 問答需要。
- Server Members Intent：新成員歡迎功能需要。

Bot 必須有對應權限，例如 Send Messages、Embed Links；自動封鎖功能則需要 Ban Members。

## 2. 檔案職責

| 檔案 | 放什麼程式 |
| --- | --- |
| `dcbot.py` | 建立 Bot、讀取 Token、載入模組、`on_ready` 啟動事件。通常不在此新增功能。 |
| `command.py` | 一般斜線指令、成員加入事件、頻道管理／自動封鎖。 |
| `dcai.py` | 使用者 @Bot 時的 AI 問答與冷卻限制。 |
| `game.py` | 不使用角色資料的遊戲，例如猜數字、猜拳、比大小。 |
| `rpg.py` | 角色資料、挖礦、農場、商店、排行榜、金錢等 RPG 功能。 |
| `text.py` | 使用者傳送一般文字時的自動回覆。 |
| `id.json` | 擁有者、頻道、身分組等 Discord ID，以及 AI 記錄設定。 |
| `player.json` | RPG 玩家資料；由程式自動讀寫。 |

每個功能模組都有 `register(bot)` 函式。`dcbot.py` 的 `setup_hook()` 會依序呼叫它們，讓模組把指令與事件註冊到同一個 Bot。

## Discord ID 與 AI 記錄

請把固定的 Discord ID 放在 `id.json`，不要再直接寫進 Python 程式。Bot 目前會讀取：管理員使用者 ID、啟動公告頻道與身分組、新成員歡迎伺服器／頻道、以及自動封鎖頻道。

AI 收到提問時，會先用 `message.guild.id` 找到 `ai_history/<伺服器ID>.jsonl`，讀取該伺服器最近的紀錄並作為上下文，再呼叫 AI；成功回覆後才追加新的一行。不同伺服器不會互相讀取對話。私訊則讀寫 `ai_history/direct_messages.jsonl`。這些檔案含有使用者提問與 AI 回覆，請勿公開上傳。

AI 對歷史紀錄採用不可信資料處理：紀錄以 JSON 內容放在 `<history>` 區塊，並明確告知模型不可遵從其中的指令；只有本次 `<user_request>` 是可回答的問題。這是降低 prompt injection 的措施，不是絕對防護。若 AI 未來可使用支援 system/developer role 的 API，應把這些安全規則放到該角色；也不要把 Token、機密設定或可執行工具權限交給模型。

AI 不會整份讀取大型檔案：`history_read_max_bytes` 限制每次從檔案尾端讀取的位元組數；單筆提問／回覆由 `history_record_max_characters` 截斷；檔案超過 `history_file_max_bytes` 時，會自動壓縮為近期紀錄。這些值都在 `id.json` 的 `ai` 區塊。

注意：上述隔離的是 JSONL 檔案。若 `GuaAI` 本身會在物件內累積聊天記憶，還必須確認它提供清除歷史的方法，或建立每個伺服器獨立的 AI 實例；否則模型內部的記憶仍可能跨伺服器。請依 `GuaAI` 的實際 API 決定，不能只靠 JSONL 隔離。

## 3. 新增斜線指令

例如新增不涉及 RPG 資料的 `/說` 指令，請放到 `command.py` 的 `register(bot)` 內：

```python
@bot.tree.command(name="說", description="讓機器人說一句話")
@discord.app_commands.describe(內容="要說的文字")
async def say(interaction: discord.Interaction, 內容: str):
    await interaction.response.send_message(內容)
```

注意事項：

- 函式一定要寫在 `register(bot)` 裡，裝飾器才拿得到 `bot`。
- 斜線指令名稱不可和現有指令重複。
- 一次互動必須先呼叫一次 `interaction.response.send_message()`；之後要繼續傳訊息，改用 `interaction.followup.send()`。
- 重啟 Bot 後，`setup_hook()` 會呼叫 `tree.sync()` 同步指令。Discord 端更新有時會需要等待片刻。

## 4. 新增文字觸發回覆

請放到 `text.py` 的 `on_message(message)` 中。例如收到「測試」就回覆：

```python
if content.startswith("測試"):
    await message.channel.send("收到測試！")
```

`startswith()` 代表文字「開頭」符合就觸發；若只希望完整相同才觸發，使用：

```python
if content == "測試":
    await message.channel.send("收到測試！")
```

不要在這些模組內使用 `@bot.event` 覆蓋 `on_message`；目前使用 `bot.add_listener(..., "on_message")`，讓文字、AI、遊戲與管理功能可以同時監聽訊息。

## 5. 新增 RPG 指令

RPG 功能都在 `rpg.py`。先用現有工具取得玩家資料：

```python
result = await get_player_or_reply(interaction)
if result is None:
    return

data, uid, monster = result
```

修改資料後一定要儲存：

```python
data[uid]["money"] += 100
save_data(data)
await interaction.response.send_message("獲得 100 呱！")
```

新增角色欄位時，要同時修改兩個地方：

1. `create_player()`：新玩家的初始值。
2. `update_all_players()` 的 `defaults`：既有玩家補上新欄位，避免讀取舊資料時出現 `KeyError`。

例如新增 `wood`：

```python
# create_player() 的 monster 內
"wood": 0,

# update_all_players() 的 defaults 內
"wood": 0,
```

`player.json` 是重要資料。大量修改遊戲系統或直接編輯 JSON 前，先備份該檔案。

## 6. 常改的設定位置

| 項目 | 位置 |
| --- | --- |
| Token | 專案根目錄 `.env` 的 `TOKEN` |
| 啟動公告頻道／身分組 | `dcbot.py` 的 `WELCOME_CHANNEL_ID`、`WELCOME_ROLE_MENTION` |
| AI 冷卻時間 | `dcbot.py` 的 `CooldownMapping.from_cooldown(1, 10, ...)`；目前每位使用者 10 秒 1 次。 |
| AI 最大提問長度 | `dcai.py` 的 `len(prompt) > 100` |
| 自動封鎖頻道 | `command.py` 的 `monitored_channels` |
| 農田耐力恢復週期 | `rpg.py` 的 `asyncio.sleep(300)`；目前 5 分鐘。 |
| 管理員加錢權限 | `rpg.py` 的 `addmoney()` 內 Discord 使用者 ID |

## 7. 修改後如何檢查

先做語法檢查：

```bash
python -m py_compile dcBot/*.py
```

沒有輸出代表語法正確。接著重新啟動 Bot，並在測試伺服器確認：

1. 終端是否顯示「斜線指令同步成功！」與登入帳號。
2. Discord 是否能看見新增或更新的斜線指令。
3. 實際執行一次修改過的功能。

## 8. 常見問題

**`ModuleNotFoundError: No module named 'discord'`**

尚未安裝套件，執行：

```bash
pip install -U discord.py python-dotenv
```

**`找不到 TOKEN`**

確認 `.env` 位於你啟動指令所在的工作目錄，並有 `TOKEN=...`。若從不同資料夾啟動，建議改用專案根目錄的 `python dcBot/dcbot.py`。

**`No module named 'ai'`**

目前 AI 模組依賴 `/home/gua/GuaAI-Qwen`。若你的 AI 專案在別處，修改 `dcbot.py` 的 `sys.path.append(...)`；若暫時不需要 AI，需另外把 `GuaAI` 初始化與 `dcai.register(self)` 移除或替換。

**文字回覆沒有反應**

確認 Developer Portal 已開啟 Message Content Intent，且 Bot 有讀取／傳送該頻道訊息的權限。

**斜線指令看不到或是舊版本**

確認 Bot 重啟時有出現「斜線指令同步成功！」。同步到 Discord 可能需要一些時間；也請確認 Bot 是用同一個 Application Token 啟動。
